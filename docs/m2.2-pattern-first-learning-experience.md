## Objective

Question Bank UX → **Pattern Learning Platform**.

Mandatory flow philosophy:

```text
Pattern → Thinking → Mechanical Algorithm → Checklist
  → Question → Feedback → Pattern Review
```

Learner outcome: *“I learned a Pattern.”* (not *“I solved a Question.”*)

---

## Modes

| Mode | Entry | Flow |
|------|-------|------|
| **Pattern Master** | Mode select → Pattern pick | Preview → Intro → Algorithm → Know-how → Checklist → Question → Result → Review |
| **Exam** | Mode select → Pattern pick | Question → Result → Review (Preview skipped) |

Selected mode persisted: `learning.studyMode.v1`

---

## Asset policy (no generation)

Assembly order in `js/pattern-lesson.js`:

1. `pattern-master-db.json` (verified gate)
2. `pattern-metadata-db.json` (documented/evidenced fields)
3. `js/pattern-engine.js` (descriptions, learning points, triggers, judgment criteria)
4. `js/ai-tutor-content/*` (profiles + calculation templates — legacy implemented assets)

If a field is missing → UI shows “자산이 없습니다” — **never invent**.
