# M2.7 Evidence Learning System

Status: **IMPLEMENTED**  
Sprint: Sprint-05  
Date: 2026-07-24  
Phase: Beta Candidate · Validation

---

## Purpose

Evidence Pad를 체크리스트가 아니라 **Learning Evidence System**으로 완성한다.

학생이 생각한 것 · 회상한 것 · 느낀 것을 **안전하게 축적**한다.  
AI는 **평가하지 않는다**.

---

## Product Goal

```
Question → Submit → Review → Retrieval Prompt → Evidence → Closing
```

Evidence = 학생 자신의 학습 자산  
Retrieval = 학생 자신의 회상 자산

---

## Absolute Non-Goals

- Question / Answer / Pattern / Knowledge / SoT 변경
- AI 생성 · Recommendation · Mastery · Confidence
- Error 추론 · 자동 피드백 · 정답 비교 · 회상 채점

---

## System Components

| Component | Role |
|-----------|------|
| Evidence Card | 20초 자기 점검 기록 |
| Retrieval Prompt | Review 후 스스로 회상 작성 |
| Recall Timeline | Pattern별 회상 변화 조회 (평가 없음) |
| Evidence Growth | Closing 집계 표시 (분석 없음) |
| Session Export v2.1 | Attempt · Evidence · Retrieval · Summaries |
