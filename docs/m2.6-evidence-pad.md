Status: **IMPLEMENTED**

---

## Purpose

Evidence Collection을 문서 작성이 아니라 **프로그램 안 체크**로 만든다.

Evidence Pad는 **Observation Tool**이다.

- 분석하지 않는다
- 추천하지 않는다
- 평가하지 않는다
- LLM / Prompt / Runtime 판단을 하지 않는다

---

## Product Goal

문제 제출 직후 **10~20초** 안에 학습 상태를 기록한다.

---

## Schema

```json
{
  "question_id": "",
  "pattern_id": "",
  "timestamp": "",
  "pattern_understanding": "",
  "error_reason": [],
  "pattern_recall": "",
  "confidence": 0,
  "next_action": [],
  "memo": ""
}
```

### Field values

| Field | Values |
|-------|--------|
| pattern_understanding | `understood` · `unclear` · `not_understood` |
| error_reason[] | `calc_error` · `concept_gap` · `condition_misread` · `incomplete_read` · `time_pressure` · `no_error` |
| pattern_recall | `immediate` · `midway` · `never` |
| confidence | `1`–`5` |
| next_action[] | `retry` · `explain_to_friend` · `review_pattern` · `review_only` |
