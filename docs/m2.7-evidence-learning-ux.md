## Purpose

Evidence Pad를 개발자용 관찰 도구가 아니라 **학생의 복습 루틴**으로 완성한다.

학생이 제출 후 Review를 읽고, **약 20초** 안에 이번 문제를 스스로 복기하도록 한다.

---

## Product Goal

Evidence는 학습의 부산물이 아니라 **복습 과정**이다.

흐름:

```
Review → Evidence → Closing
```

---

## Absolute Non-Goals

- Question / Answer / Pattern / Knowledge / SoT 변경
- AI 생성 · Recommendation · Mastery · Confidence 계산
- Error 추론 · 자동 피드백 생성
