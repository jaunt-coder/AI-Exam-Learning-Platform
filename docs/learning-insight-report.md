```text
Evidence → Insight → Candidate Requirement → Evidence Backlog

```

## Rules

1. 가정으로 인사이트를 만들지 않는다.
2. Insight가 Candidate가 되면 Evidence Strength(F×S×I)를 산출한다.
3. Insight만으로 Roadmap에 올리지 않는다. Human Approval된 `Approved Candidate`만 가능.
4. 상세 요구사항은 `recommendation-requirements.md` / `coach-requirements.md`에 기록한다.
