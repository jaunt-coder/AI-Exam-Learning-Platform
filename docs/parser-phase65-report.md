## 4. 해석

- Cell 내부에서만 Token을 재조립한다. Row/Column 이동·Cell merge·새 숫자/문자 생성 금지.
- 복원 예: `390+,+000`→`390,000`, `￦+390,000`→`￦390,000`, `20+X+3`→`20X3`, `현재+가치`→`현재가치`, `공사+원+가`→`공사원가`, `단일+금액+￦+1`→`단일금액 ￦1`.
- table fidelity / cell recall은 **표 검출 문항** 기준 셀 표면 품질이다 (Phase 6 universe detection 비율과 별개).
- 다음 단계: 품질 충분 시 Stage 7 JSON Builder.
